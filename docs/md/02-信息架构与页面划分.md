# 02｜信息架构与页面划分（iOS 风格明显）

目标：让用户在 3 秒内知道“我有什么、快过期什么、下一步做什么”，同时保持典型 iOS 的导航与层级感。

## 导航总览（推荐 IA）

采用 **Tab Bar（主分区） + NavigationStack（层级） + Sheet（轻量任务）** 的组合。

- **Tab 1：食材**（核心）
  - 列表（分组/筛选）
  - 食材详情
  - 新增/编辑（表单 Sheet）
- **Tab 2：提醒**（临期/过期）
  - 临期列表（按天分组）
  - 批量处理（用掉/丢弃/延期）
- **Tab 3：设置**（账号/同步/通知/数据）
  - 登录/绑定手机号/微信
  - 云同步开关
  - 通知策略（提前几天、时段）
  - 导入导出（可选）

> 若想更“苹果”，避免在首页塞太多卡片。工具型 App 以“列表 + 搜索 + 筛选”更耐用。

## 内容区域如何区分（模块边界）

把内容区分为三类信息，分别对应不同 UI 容器：

- **集合信息（List）**：食材清单、提醒清单  
  - iOS 习惯：`List` + `Section` + `swipeActions`
- **单体信息（Detail）**：食材详情页  
  - iOS 习惯：顶部大标题 + 分组表单风格（Form / 分组列表）
- **任务信息（Sheet）**：新增/编辑/筛选  
  - iOS 习惯：任务用 Sheet，确认/取消在导航栏

## 核心页面说明（你现在最需要清晰的“产品骨架”）

### 1）食材列表（Tab：食材）

- 顶部：`Search`（搜索）
- 次级：筛选 Chips（位置/状态/标签）或放到筛选 Sheet
- 内容：按“状态”或“位置”分 `Section`
  - 临期（置顶）
  - 新鲜
  - 过期（可折叠）
- 行为：
  - 点进详情
  - 左滑快捷：用掉 / 丢弃 / 延期
  - 右上角：`+` 新增

### 2）提醒列表（Tab：提醒）

- 以“今天/明天/本周”分组最直观
- 支持批量处理（多选模式）：
  - 一键“已用掉”
  - 一键“延期 1 天/3 天”

### 3）食材详情（从列表 push）

- 关键信息：名称、数量、位置、到期日、标签、备注
- 强操作放底部：用掉 / 丢弃（Primary actions）
- “编辑”放右上角

### 4）新增/编辑食材（Sheet）

表单字段顺序（减少输入成本）：

1. 名称（支持常用/最近输入）
2. 数量 + 单位（可选，默认 1）
3. 位置（默认“冰箱-冷藏”之类）
4. 到期日（日期选择器）
5. 标签/备注（可选）

## iOS 风格明显的关键点（别做“安卓大杂烩”）

- 主页面坚持 **一屏一个主任务**：列表就是列表，不混搭过多运营卡片
- 交互遵循系统范式：`NavigationStack` push、`Sheet` modal、`Toolbar` 放动作
- 大量使用系统组件：`List`、`Section`、`Searchable`、`SwipeActions`
- 文案短、层级清楚，留白足
