# 00｜产品目标与范围

## 一句话定义

一款「帮助家庭/个人把冰箱与囤货变清楚」的食材管理 App：**记录—提醒—消耗—复盘**，减少浪费、提高做饭效率。

## 目标用户（先聚焦）

- **家庭主厨/经常做饭的人**：买菜频繁、容易忘记存货与过期
- **独居/合租**：冰箱空间有限、食材周转快但更怕遗忘

## 核心价值（必须做对的 3 件事）

- **清单清晰**：我现在有什么？在哪里？还剩多少？
- **临期提醒**：哪些快过期？优先吃什么？
- **使用闭环**：能快速标记“用掉/扔掉/做成菜”，形成习惯

## 成功指标（先用可量化的）

- **D1 完成记录率**：首次打开后 10 分钟内完成“添加 ≥3 个食材”的比例
- **周活跃与复访**：7 天内至少打开 3 次
- **浪费降低的主观感受**：用户在反馈中提到“更少扔东西/更省心”

## MVP 范围（第一阶段只做这些）

- **食材库（我的食材）**
  - 新增/编辑/删除食材
  - 关键字段：名称、数量/单位、存放位置、购买日/到期日、备注、标签
  - 状态：新鲜 / 临期 / 过期 / 已用完（归档）
- **提醒**
  - 临期提醒（到期前 N 天）
  - 过期提醒（可选）
- **快速操作**
  - 列表滑动操作：用掉、丢弃、延长保质期（改到期日）
- **搜索与筛选**
  - 关键字搜索
  - 按位置/状态/标签筛选

## 暂不做（避免范围失控）

- 菜谱/智能推荐（后续）
- 购物清单自动联动（后续）
- 多人共享家庭空间（后续，和账号体系强绑定）
- 扫码识别/票据识别（后续）

## 关键产品决策（先写结论）

- **默认允许不登录先体验**：先跑通“添加—查看—临期提醒”的价值；在“需要跨设备/云同步/家庭共享”时再引导登录（见 `01-登录与账号体系-策略.md`）。
