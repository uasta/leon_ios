# Leon iOS 技术架构文档

## 项目概述

当前版本不是“大而全的 AI 厨房平台”，而是先完成一条清晰主链路：

1. 录入食材
2. 用食材进入推荐
3. 在“我的”沉淀登录、点赞、收藏、历史

V2 再扩展：

- 拍照识别食材并打框
- 口味偏好
- 用户标签

## 当前功能架构

## 技术栈建议

### iOS 客户端

- **语言**：Swift 5.9+
- **UI**：SwiftUI
- **导航**：TabView + NavigationStack + Sheet
- **状态管理**：`@State`、`@ObservableObject`、Store 层
- **网络**：URLSession
- **本地数据**：SwiftData 或轻量本地 Store

### 识别能力

- **V1 小票识别**：
  - Vision OCR 负责文本识别
  - 服务端负责解析商品候选
- **V2 拍照识别打框**：
  - Vision / 云端模型负责目标检测
  - 返回框选坐标和识别标签

### 服务端

- 以 HTTP API 为主
- 按业务域拆分：
  - Ingredients
  - Recipes / Recommendations
  - User Actions
  - OCR

## 当前仓库结构映射

当前仓库已经有的模块基础：

```text
leon_ios/
├── AppRootView.swift
├── Features/
│   ├── Ingredients/
│   ├── Presets/

│   └── Settings/

```

对齐当前产品规划后，建议目标结构逐步过渡为：

```text
leon_ios/
├── AppRootView.swift
├── Features/
│   ├── Ingredients/
│   ├── Recommend/
│   ├── Me/
│   ├── OCR/
│   └── Auth/
├── Models/
├── Stores/
├── Services/
└── ContentView.swift
```

说明：

- `Reminders` 和 `Settings` 不再是底部主模块
- 相关能力应分别收敛到 `Ingredients` 和 `Me`

## 核心流程实现建议

### 1. 手动录入食材

```text
用户输入食材
  ↓
本地表单校验
  ↓
创建 Ingredient
  ↓
刷新食材列表
```

### 2. 小票识别导入

```text
用户上传小票
  ↓
OCR 识别文本
  ↓
服务端解析候选食材
  ↓
用户确认 / 修正
  ↓
批量写入 Ingredient
```

### 3. 食材跳转推荐

```text
用户在食材页勾选食材
  ↓
记录 selectedIngredientNames
  ↓
跳转推荐页
  ↓
请求 `POST /api/v1/recommendations/by-ingredients`
  ↓
展示瀑布流结果
```

### 4. 点赞 / 收藏 / 历史

```text
用户进入食谱详情
  ↓
查看详情时写入历史
  ↓
点击点赞 / 收藏
  ↓
同步到“我的”
```

## 数据模型建议

### Ingredient

```swift
struct Ingredient: Identifiable, Codable {
    let id: String
    var name: String
    var quantity: String
    var unit: String
    var note: String?
}
```

### RecipeSummary

```swift
struct RecipeSummary: Identifiable, Codable {
    let id: Int
    var title: String
    var coverURL: String?
    var matchReason: String?
    var liked: Bool
    var favorited: Bool
}
```

### RecipeDetail

```swift
struct RecipeDetail: Identifiable, Codable {
    let id: Int
    var title: String
    var coverURL: String?
    var ingredients: [String]
    var steps: [String]
    var liked: Bool
    var favorited: Bool
}
```

### UserPreference

```swift
struct UserPreference: Codable {
    var tabOrder: [String]
}
```

## 状态管理建议

至少拆成以下 Store：

- `IngredientStore`
- `RecommendationStore`
- `SessionStore`
- `ProfileStore`
- `PreferenceStore`

V1 不建议一开始就把所有状态糅成一个超大 Store。

## 版本推进建议

### Phase 1

- 食材列表与手动录入
- 食材勾选与跳转推荐
- 推荐流和详情页骨架

### Phase 2

- 登录
- 点赞 / 收藏 / 历史
- Tab 顺序偏好

### Phase 3

- 小票识别

### Phase 4

- 拍照识别打框
- 口味偏好
- 用户标签

## 当前不建议投入的方向

- 会员订阅
- 社区问答
- 语音指导
- 厨具识别
- IoT 设备联动

这些方向会显著拉高复杂度，但不直接服务当前 V1 主链路。
