# 食材管理 App - 技术架构文档

## 项目概述

一款融合 AI 的家庭食材管理和做饭攻略应用，注重 iOS 原生体验和流畅交互。

## 技术栈

### 前端技术

- **开发语言**: Swift 5.9+
- **UI 框架**: SwiftUI（声明式 UI，类似 React）
- **架构模式**: MVVM（Model-View-ViewModel）
- **状态管理**: @State, @StateObject, @ObservableObject（类似 React Hooks）

### 核心功能技术

#### 1. 相机与图像识别

- **AVFoundation**: 相机控制和实时预览
- **Vision Framework**: 图像处理和文字识别（OCR）
- **Core ML**: 本地机器学习模型（可选）
- **PhotosUI**: 相册访问和图片选择

#### 2. AI 集成

- **URLSession**: HTTP 网络请求
- **云端 AI 服务**:
  - OpenAI Vision API（图像识别）
  - OpenAI GPT-4（菜谱生成、烹饪建议）
  - 或国内替代：通义千问、文心一言

#### 3. 数据存储

- **SwiftData**: 本地数据持久化（iOS 17+，类似 ORM）
- **UserDefaults**: 简单配置存储
- **FileManager**: 图片文件存储
- **iCloud CloudKit**: 云端同步（可选）

#### 4. 会员与支付

- **StoreKit 2**: 应用内购买（订阅制会员）
- **RevenueCat**: 第三方订阅管理服务（推荐）
  - 简化收据验证
  - 跨平台订阅管理
  - 提供分析面板

### 后端服务

#### 方案一：Supabase（推荐）

- **数据库**: PostgreSQL
- **认证**: 内置用户系统
- **存储**: 图片上传
- **实时订阅**: 数据同步
- **Edge Functions**: 服务端逻辑
- **优势**: 免费额度大，开发速度快

#### 方案二：Firebase

- **Firestore**: NoSQL 数据库
- **Authentication**: 用户认证
- **Storage**: 文件存储
- **Cloud Functions**: 服务端逻辑
- **优势**: Google 生态，文档完善

### 辅助工具

- **Xcode 15+**: 官方 IDE
- **SF Symbols**: 苹果官方图标库
- **Postman**: API 测试
- **Git**: 版本控制
- **TestFlight**: 内测分发

## 核心功能实现思路

### 1. 拍照识别食材流程

```
用户点击拍照 
  ↓
打开相机界面（AVFoundation）
  ↓
拍照/选择相册图片
  ↓
图片预处理（压缩、裁剪）
端 AI 服务
  ↓
AI 返回识别结果（食材列表）
  ↓
用户确认/编辑
  ↓
保存到本地数据库（SwiftData）
```

### 2. 会员订阅流程

```
用户点击订阅
  ↓
加载商品列表（StoreKit 2）
  ↓
展示订阅选项（月付/年付）
  ↓
用户选择并支付
  ↓
App Store 处理支付
  ↓
收到购买成功回调
  ↓
发送收据到后端验证（RevenueCat）
  ↓
后端验证通过，开通会员
  ↓
更新本地会员状态
```

### 3. AI 菜谱推荐流程

```
用户查看现有食材
  ↓
点击"推荐菜谱"
  ↓
构建 AI 提示词（包含食材列表）
  ↓
调用 OpenAI API
  ↓
AI 返回菜谱建议（JSON 格式）
  ↓
解析并展示菜谱卡片
  ↓
用户点击查看详情
```

## 数据模型设计

### Ingredient（食材）

```swift
@Model
class Ingredient {
    var id: UUID
    var name: String              // 食材名称
    var category: String          // 分类（蔬菜、肉类等）
    var quantity: String          // 数量
    var unit: String              // 单位
    var expiryDate: Date?         // 过期日期
    var imageURL: String?         // 图片地址
    var addedDate: Date           // 添加日期
    var location: String?         // 存放位置（冰箱、冷冻等）
}
```

### Recipe（菜谱）

```swift
@Model
class Recipe {
    var id: UUID
    var title: String             // 菜谱名称
    var ingredients: [String]     // 所需食材
    var steps: [String]           // 烹饪步骤
    var cookingTime: Int          // 烹饪时间（分钟）
    var difficulty: String        // 难度
    var imageURL: String?         // 图片
    var isFavorite: Bool          // 是否收藏
    var createdDate: Date         // 创建日期
}
```

### User（用户）

```swift
class User: ObservableObject {
    @Published var isPremium: Bool = false
    @Published var subscriptionType: String?
    @Published var expiryDate: Date?
}
```

## 性能优化策略

1. **图片优化**
  - 拍照后压缩到合理尺寸（1024x1024）
  - 使用 WebP 格式存储
  - 懒加载和缓存
2. **网络优化**
  - 请求合并和防抖
  - 离线缓存
  - 失败重试机制
3. **动画优化**
  - 使用 SwiftUI 原生动画
  - 避免过度渲染
  - 合理使用 @State 和 @Binding
4. **数据库优化**
  - 索引关键字段
  - 分页加载
  - 后台线程操作

## 安全考虑

1. **API 密钥管理**
  - 不要硬编码在客户端
  - 通过后端代理调用 AI 服务
2. **用户数据**
  - 本地数据加密
  - 敏感信息使用 Keychain 存储
3. **内购验证**
  - 必须通过后端验证收据
  - 防止越狱破解
