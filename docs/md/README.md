# 文档索引（Leon iOS）

本目录用于沉淀当前产品规划、信息架构、流程、接口和技术方案，目标是让产品、设计、iOS、后端始终对同一套版本说话。

## 当前产品基线

- V1 主导航为 3 个 Tab：`食材`、`推荐`、`我的`
- `食材` 与 `推荐` 支持用户自定义顺序，`我的` 固定在右侧
- V1 重点是：食材录入与管理、菜谱推荐与详情、登录与点赞收藏历史
- V2 重点是：拍照识别食材并打框、口味偏好、用户标签

## 约定

- 文档优先记录“结论 + 原因 + 边界”，避免只堆功能名词
- 若产品规划变更，先改 `00`、`02`、`03`、`07`，再同步其余文档
- 历史迭代文档保留时间语境，但不得与当前版本基线相冲突
