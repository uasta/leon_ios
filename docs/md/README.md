# 文档索引（食材管理 iOS App）

本目录专门存放产品/设计/技术相关的 Markdown 文档，便于逐步完善与对齐。

## 快速入口

- `00-产品目标与范围.md`：你要做什么、不做什么、衡量标准
- `01-登录与账号体系-策略.md`：手机号 + 微信授权登录的取舍与推荐方案
- `02-信息架构与页面划分.md`：iOS 风格明显的页面结构、导航与模块边界
- `03-核心用户流程.md`：从首次打开到日常使用的关键动线
- `04-体验与动效原则.md`：丝滑/流畅的转场、列表、输入体验落地原则
- `05-迭代记录-2026-04-16.md`：本次迭代（筛选/批量/FAB/预设）的决策与待验证
- `06-后端推进大纲-2026-04-23.md`：当前阶段最重要的后端推进顺序、分工与优先级建议

## 约定

- 文件命名以数字前缀排序，便于持续追加（如 `05-xxx.md`）。
- 优先写“决策与原因”，避免只堆功能清单。
