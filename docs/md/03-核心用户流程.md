# 03｜核心用户流程

## Flow A：首次进入

目标：让用户尽快理解这不是单纯记账式食材 App，而是“录入食材后马上能看到推荐”。

- 打开 App
- 默认进入 `食材` Tab
- 空状态展示两个主入口：
  - 手动添加食材
  - 小票识别导入

## Flow B：录入食材

### 路径 1：手动录入

- 用户点击“添加食材”
- 输入食材名称
- 可继续手打，也可通过输入搜索选择候选
- 保存后返回食材列表

### 路径 2：小票识别

- 用户上传或拍摄小票
- 系统返回候选食材列表
- 用户勾选、修正、确认
- 批量写入食材列表

## Flow C：从食材跳到推荐

- 用户在食材列表中勾选 1 个或多个食材
- 点击“去推荐”
- 跳转到 `推荐` Tab
- 推荐页基于所选食材展示结果
- 用户继续搜索或直接浏览瀑布流菜谱

## Flow D：推荐浏览与沉淀行为

- 用户在推荐页搜索菜谱
- 浏览瀑布流食谱卡片
- 进入食谱详情
- 在详情里执行：
  - 点赞
  - 收藏
- 系统写入浏览历史

## Flow E：我的

- 用户进入 `我的`
- 未登录时：
  - 展示登录入口
- 已登录时：
  - 查看点赞
  - 查看收藏
  - 查看历史

## Flow F：2.0 预留

- 用户直接拍照识别食材
- 识别结果带框展示
- 结合口味偏好和用户标签继续优化推荐结果
