# iOS 原生开发 - 从前端到 iOS 完整指南

## 前言：给前端开发者的话

作为前端开发者，你已经具备了很多优势：

- ✅ 理解组件化思维（SwiftUI 和 React 非常相似）
- ✅ 熟悉状态管理概念
- ✅ 掌握异步编程（async/await）
- ✅ 了解 UI 布局和样式

**Swift 和 JavaScript 的对比**：

- Swift 是强类型语言（类似 TypeScript）
- SwiftUI 是声明式 UI（和 React 几乎一样的思路）
- 你会发现很多概念是相通的！

### 2. 网络请求

**类似于**：fetch API 或 axios

```swift
// 定义 API 服务
class AIService {
    func recognizeIngredients(image: UIImage) async throws -> [String] {
        // 1. 准备请求
        let url = URL(string: "https://api.openai.com/v1/chat/completions")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("Bearer YOUR_API_KEY", forHTTPHeaderField: "Authorization")
        
        // 2. 构建请求体
        let body = [
            "model": "gpt-4-vision-preview",
            "messages": [
                ["role": "user", "content": "识别图片中的食材"]
            ]
        ]
        request.httpBody = try JSONEncoder().encode(body)
        
        // 3. 发送请求
        let (data, _) = try await URLSession.shared.data(for: request)
        
        // 4. 解析响应
        let response = try JSONDecoder().decode(AIResponse.self, from: data)
        return response.ingredients
    }
}

// 在视图中使用
struct CameraView: View {
    @State private var ingredients: [String] = []
    let aiService = AIService()
    
    func analyzeImage(_ image: UIImage) {
        Task {
            do {
                ingredients = try await aiService.recognizeIngredients(image: image)
            } catch {
                print("识别失败: \(error)")
            }
        }
    }
}
```

### 4. 内购功能（StoreKit 2）

```swift
import StoreKit

@MainActor
class StoreManager: ObservableObject {
    @Published var products: [Product] = []
    @Published var purchasedProductIDs: Set<String> = []
    
    private let productIDs = ["premium_monthly", "premium_yearly"]
    
    // 加载商品
    func loadProducts() async {
        do {
            products = try await Product.products(for: productIDs)
        } catch {
            print("加载商品失败: \(error)")
        }
    }
    
    // 购买
    func purchase(_ product: Product) async throws {
        let result = try await product.purchase()
        
        switch result {
        case .success(let verification):
            // 验证购买
            let transaction = try checkVerified(verification)
            purchasedProductIDs.insert(transaction.productID)
            await transaction.finish()
        case .userCancelled:
            break
        case .pending:
            break
        @unknown default:
            break
        }
    }
    
    func checkVerified<T>(_ result: VerificationResult<T>) throws -> T {
        switch result {
        case .unverified:
            throw StoreError.failedVerification
        case .verified(let safe):
            return safe
        }
    }
}

enum StoreError: Error {
    case failedVerification
}
```

### 2. 创建数据表

```sql
-- 用户表
create table users (
  id uuid primary key default uuid_generate_v4(),
  email text unique not null,
  is_premium boolean default false,
  created_at timestamp default now()
);

-- 食材表
create table ingredients (
  id uuid primary key default uuid_generate_v4(),
  user_id uuid references users(id),
  name text not null,
  quantity text,
  expiry_date date,
  image_url text,
  created_at timestamp default now()
);

-- 菜谱表
create table recipes (
  id uuid primary key default uuid_generate_v4(),
  user_id uuid references users(id),
  title text not null,
  ingredients jsonb,
  steps jsonb,
  created_at timestamp default now()
);
```

### 3. iOS 集成 Supabase

```swift
// 安装 Supabase Swift SDK
// File → Add Package Dependencies
// 输入: https://github.com/supabase/supabase-swift

import Supabase

// 配置客户端
let supabase = SupabaseClient(
    supabaseURL: URL(string: "YOUR_SUPABASE_URL")!,
    supabaseKey: "YOUR_ANON_KEY"
)

// 使用示例
class SupabaseService {
    func fetchIngredients() async throws -> [Ingredient] {
        let response: [Ingredient] = try await supabase
            .from("ingredients")
            .select()
            .execute()
            .value
        return response
    }
    
    func addIngredient(_ ingredient: Ingredient) async throws {
        try await supabase
            .from("ingredients")
            .insert(ingredient)
            .execute()
    }
}
```

## 常见问题 FAQ

### Q1: 我需要 Mac 吗？

**A**: 是的，iOS 开发必须使用 Mac。你的 Mac mini 完全够用。

### Q2: 学习 Swift 需要多久？

**A**: 如果你有前端经验，1-2 周可以掌握基础，1 个月可以开始开发项目。

### Q3: SwiftUI 和 UIKit 选哪个？

**A**: 新项目强烈推荐 SwiftUI，语法更现代，开发效率更高。

### Q4: 免费账号够用吗？

**A**: 学习阶段够用，但开发正式项目需要付费账号（内购、TestFlight）。

### Q5: 如何保护 API 密钥？

**A**: 不要硬编码在客户端，通过后端代理调用 AI 服务。

### Q6: 模拟器和真机有什么区别？

**A**: 模拟器快但不能测试相机、推送等功能，真机测试更准确。

### Q7: 如何调试网络请求？

**A**: 使用 Xcode 的 Network Debugger 或 Charles Proxy。

### Q8: 遇到问题怎么办？

**A**: 

1. 查看 Xcode 错误提示（通常很详细）
2. Google 搜索错误信息
3. Stack Overflow
4. 官方文档
